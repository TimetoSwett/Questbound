# Questbound — Pathfinder 1e Campaign Companion

## Overview
A full-stack web app for hosting tabletop RPG (Pathfinder 1e) campaigns with character sheets, DM wiki, and three map types.

## Theme
- "Map on a table" cartography aesthetic (LIGHT theme). Aged parchment/paper background (HSL 39 40% 83%) with faint cartographer grid lines, coffee-stain blotches and a vignette on the body (background-attachment: fixed). Cards are fresh parchment (HSL 40 48% 91%).
- Sepia ink text (HSL 25 40% 18%), burnt-sienna/oxblood primary (HSL 15 60% 40%), map-teal accent (HSL 193 42% 33%).
- Both :root and .dark CSS-var blocks hold the SAME light paper palette (html is forced class="dark"), so it renders identically regardless of the theme class.
- Map surfaces themed as paper: region-map SVG bg tan, battle-map grid lines brown ink. Semantic stat colors darkened for light bg (green-700 / red-600).
- Font hierarchy: DM Sans body, Plus Jakarta Sans display headings, JetBrains Mono for stats/numbers

## Architecture
- Auth: email+password via Auth.js v5, JWT strategy
- DB: PostgreSQL with Prisma. Character stats as individual columns; skills/equipment/feats/spells/classes as JSON arrays
- File uploads: S3 presigned URLs (character portraits, world map images) — always public
- Rich text: TipTap editor for wiki pages and character notes
- Maps: three types under World tab — World Map (image+pins), Battle Map (CSS grid), Region Map (SVG node graph)

## Key Routes
- `/login`, `/signup` — auth pages
- `/dashboard` — campaign list, create/join
- `/campaign/[id]` — campaign shell with tabs: Characters | World | Players (DM only)

## Campaign System
- 5-char invite codes (alphanumeric, no ambiguous chars)
- DM role is per-campaign, not global
- Players can have multiple characters per campaign

## User Preferences
- Pathfinder 1e as the primary system (full PF1e skill list, AC/saves/CMB/CMD formulas)
- Obsidian markdown import support in wiki (parses `[[wikilinks]]`)
- Three map types: image-based world map with pins, tactical grid battle map with fog-of-war, SVG node-based region map
- Invite codes (no email invites)
